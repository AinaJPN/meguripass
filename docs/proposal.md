# MeguriPass

_Theme park digital stamp rally turning visits into collectible Solana NFTs_

## Summary

MeguriPass lets amusement parks and event venues run digital stamp rallies where visitors scan QR codes at attractions to mint low-cost compressed NFT stamps on Solana. Completing a full set unlocks a token-gated fan community and real-world rewards, blending Japan's beloved stamp rally culture with Web3 collectibles.

## Target users

Theme park & event visitors, families, anime/character fans who enjoy collecting

## Problem

Traditional paper stamp rallies have no lasting value, no community connection, and limited engagement data for venues.

## Solution

Replace paper stamps with cheap, instant compressed NFTs tied to QR check-ins, creating a persistent collectible and a gated community for completers.

## MVP features

- QR code check-in at each attraction mints a compressed NFT stamp
- Progress tracker UI showing collected vs remaining stamps
- Completing full set unlocks token-gated Discord/LINE community
- Leaderboard ranking top collectors with seasonal rewards
- Simple venue dashboard to create and manage stamp campaigns

## Chains

Solana

## Tech

Anchor, Metaplex Bubblegum (compressed NFTs), Next.js, Phantom Wallet Adapter, Supabase, QR code scanning (Web)

## Category

Consumer

## Why now

Compressed NFTs make mass-scale, low-cost stamp issuance viable for the first time, and Japanese leisure venues are actively exploring digital engagement tools.

## Roadmap

- Pilot with one real amusement park or local event
- Add merchandise redemption marketplace for completed sets
- Build shared multi-venue loyalty network standard
